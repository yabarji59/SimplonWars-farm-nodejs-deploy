SimplonWars Farm

API Star Wars pour la formation Dev FRONT LENS P4

Une API REST qui combine la ferme d'animaux classique avec l'univers Star Wars !

🚀 API Endpoints

GET /api
Récupère tous les animaux Star Wars et leurs sons
GET /api/random
Retourne un animal Star Wars aléatoire avec son son et sa planète
GET /api/random/{count}
Retourne plusieurs animaux aléatoires (1-10 maximum)
GET /api/planet/{planetName}
Récupère tous les animaux d'une planète spécifique
GET /api/stats
Retourne des statistiques sur les animaux et planètes
GET /api/search/{query}
Recherche un animal par nom (recherche partielle)
